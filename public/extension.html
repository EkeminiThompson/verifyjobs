How to get it

1

Open the Chrome Web Store listing

Click Add to Chrome — Free above (or search “VerifyJobs” in the Chrome Web Store). Works on Chrome, Edge, Brave, and other Chromium browsers.

2

Confirm the install

Chrome will show the permissions the extension needs (active tab, context menu, storage). These are only used when you choose to analyse a job.

3

Pin it (optional) and start checking

Click the puzzle icon in the toolbar → pin VerifyJobs. Then use the popup, right-click menu, or the floating button on major job sites.

What you can do

Three ways to analyse
  • Paste Text — job description, email, or WhatsApp/Telegram message
  • URL — paste any job link; the server fetches and analyses the page
  • This Page — analyse the tab you currently have open

Results show a risk score (0–100), legitimacy score, status badge, red flags, positive signals, and a plain-English recommendation — all inside the popup.

Privacy in short

The extension only sends content when you click Analyse. It does not track your browsing, does not show ads, and does not require an account. The only preference stored locally is the optional API server address (default: verifyjobs.org).
