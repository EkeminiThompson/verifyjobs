Chrome Extension Privacy Policy

This policy covers the VerifyJobs Chrome extension. It explains what data the extension handles and how it is used.

Last updated: August 7, 2026
No personal data collected
No tracking or ads
Only analyses what you submit
1. What this extension does

The VerifyJobs Chrome extension lets you check job postings for scam signals without leaving the page. You can paste text, submit a URL, or analyse the current tab. The extension sends that content to the VerifyJobs analysis service and shows the risk score and flags in the popup.

2. Data the extension handles

When you run an analysis, the extension may send:

  • Job description text you paste or select
  • A job URL you enter or the URL of the current page
  • An optional job title you type

Important: This content is sent only when you click Analyse (or use the context menu / floating button). It is processed by the same VerifyJobs engine used on the website. The extension itself does not store job text, URLs, or results on your device beyond the current session needed to show the popup.

3. Local storage

The extension stores only one preference on your device:

  • API Base URL — the server address used for analysis (default: https://verifyjobs.org). You can change this in the extension Options page.

No browsing history, cookies from other sites, or personal identifiers are stored by the extension.

4. Permissions explained

The extension requests these Chrome permissions:

  • activeTab / scripting — to read the current page URL or selected text when you choose to analyse it
  • contextMenus — to add “Check with VerifyJobs” to the right-click menu
  • storage — to save your API Base URL preference
  • sidePanel — optional side-panel UI
  • Host permissions for verifyjobs.org (to call the analysis API) and major job sites (so the optional floating button can appear)

The extension does not read your email, passwords, or data from unrelated websites.

5. How the server uses the data

Job text and URLs sent by the extension are handled under the main VerifyJobs.org Privacy Policy:

  • Processed in memory for analysis
  • Not stored permanently as personal profiles
  • Not sold or used for advertising
  • Basic technical logs (e.g. IP for rate limiting) may be kept for security
6. No tracking or third-party analytics

The extension does not include advertising SDKs, tracking pixels, Google Analytics, or any third-party analytics. It does not build a profile of your browsing activity.

7. Children

The extension is not directed at children under 13. We do not knowingly collect data from children.

8. Changes

We may update this policy when the extension’s behaviour changes. The “Last updated” date will be revised. Continued use after changes means you accept the updated policy.
